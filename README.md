# AK Theme (release build)

Ready-to-install build of [AK Theme](https://github.com/Anupkankale/aktheme): compiled assets and runtime PHP packages
included, no build step needed. Source and tooling live on the `main` branch.

## Install

- **Zip:** download `aktheme-<version>.zip` from the [Releases page](https://github.com/Anupkankale/aktheme/releases)
  and upload it in WordPress: Appearance > Themes > Add New > Upload Theme.
- **Git:** `git clone -b release https://github.com/Anupkankale/aktheme.git wp-content/themes/aktheme`

Requires WordPress 6.6+ and PHP 8.2+.
